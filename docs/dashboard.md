# Agent Bridge Command Center Dashboard & Live Display

*Document Version: 1.2.0 (Mission 4 Ship-Ready)*

---

## 1. Overview

The Agent Bridge Command Center is an operator dashboard running on `127.0.0.1:8768`. It allows the operator to monitor live inter-agent message exchanges, track execution latencies, inspect the SQLite audit log, and observe live streaming tokens.

---

## 2. Starting the Dashboard

```bash
node bin/bridge.js dashboard --port 8768
```

On startup, the command:
1. Generates a cryptographically random 24-byte operator token.
2. Binds exclusively to loopback (`127.0.0.1`).
3. Prints the authorization URL and operator token to stdout.
4. Protects all endpoints with constant-time token comparison (`crypto.timingSafeEqual`).

---

## 3. Security Protections

1. **Host Header Guard:** Rejects requests where `Host` is not `127.0.0.1` or `localhost` with `403 Forbidden`.
2. **Origin Header Rejection:** Browser requests with foreign `Origin` headers are blocked (`403 Forbidden`).
3. **Strict Content Security Policy (CSP):**
   ```
   default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self'
   ```
4. **No innerHTML with Untrusted Data:** All rendered UI elements use DOM `textContent` or sanitized text nodes to prevent XSS.
5. **Redaction Engine:** All secrets (`sk-*`, `API_KEY`, Bearer tokens) are redacted before serialization into the dashboard stream.

---

## 4. Live Display Streaming & Tailing

Results stream in real time to the dashboard and the CLI via `BridgeDisplayManager` (`src/display/bridge-display-manager.js`).

### Tailing a Request via CLI
```bash
node bin/bridge.js tail <requestId>
```
Streams chunks as they are generated by the worker model and prints the final committed response before the initiating agent's turn. No intermediate status or progress events enter the model's token context.
